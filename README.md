# Единый API-портал интеграций

Статический справочный портал по интеграциям, BackOffice, работе с инцидентами и материалам API.

## Запуск

1. Скачайте проект целиком (кнопка **Code → Download ZIP**) или клонируйте репозиторий.
2. Не распаковывая отдельно папки проекта, откройте **index.html** в браузере.
3. Изображения и локальные PDF находятся в **assets/** и **api_materials/**; сохраняйте эту структуру папок.

Сборка и установка зависимостей не требуются. Портал работает как автономная статическая страница.


## Состав

- **index.html** — главная страница портала.
- **assets/** — иллюстрации и скриншоты, используемые разделами.
- **api_materials/** — исходные PDF-файлы, доступные для скачивания.

## Источники и распространение

Часть содержимого и иллюстраций перенесена из Atlassian Confluence. Передайте доступ только тем, кому разрешено видеть внутренние материалы. Примеры ключей и токенов, найденные в FAQ, замаскированы в портале. Не добавляйте в Git новые учётные данные, API-ключи или токены; используйте защищённое хранилище. Оставшиеся внешние изображения FAQ доступны по исходным URL и могут требовать доступа к исходной базе знаний.
