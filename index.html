B2B API

Интеграция B2B-компании (оператора) с агрегатором

Исходная документация: https://transaction.uat.agg.bet/b2b-swagger/docs

Описание

Interaction between the B2B Company (client) platform (site) and the aggregator is carried out through the REST API. Each request endpoint accepts a call with JSON-encoded data fields.

To start interaction with aggregator API the following is necessary:

  1. To receive b2b_company_id - a unique identifier of your company in the aggregator system, if your company has several platforms (sites) you need to create a B2B company in the aggregator system and get ids for each one
  2. Generate API Key for each your platform (site) in aggregator system (you can log in to the aggregator system as a user and generate an API Keys or ask the aggregator employee) and save their values
  3. Generate JWT Bearer token for each your platform (site) using saved API Key value and claims and sha256 hash function. Bearer token will be used for authorization
  4. Receive - server base url to send requests to aggregator API
  5. Provide - platform urls (for Bet/Win/Jackpot, Refund, Balance requests) where aggregator sends requests must be specified in aggregator system
