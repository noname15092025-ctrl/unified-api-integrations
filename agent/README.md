# ИИ-агент портала — подключение (бесплатно)

Чат-агент справа внизу на сайте отправляет вопрос в маленький прокси
(Cloudflare Worker), а тот — в модель **Google Gemini**. Ключ модели лежит
**секретом в воркере**, а не в коде сайта, поэтому в публичном репозитории
его нет.

Всё можно поднять **бесплатно и без привязки карты**:
- Cloudflare Workers — бесплатный тариф (100 000 запросов/день).
- Google Gemini — бесплатный ключ в Google AI Studio (лимит запросов в
  минуту, для поддержки с запасом).

---

## Шаг 1. Бесплатный ключ Gemini

1. Открой <https://aistudio.google.com/app/apikey> (вход по Google-аккаунту).
2. **Create API key** → скопируй ключ (вида `AIza...`). Карта не нужна.

## Шаг 2. Воркер на Cloudflare

1. Зарегистрируйся на <https://dash.cloudflare.com> (бесплатно).
2. **Workers & Pages → Create → Create Worker** → задай имя
   (например `api-portal-agent`) → **Deploy**.
3. **Edit code** → удали шаблон, вставь содержимое файла
   [`worker.js`](worker.js) → **Deploy**.
4. **Settings → Variables and Secrets**:
   - добавь **Secret** `GEMINI_API_KEY` = ключ из шага 1;
   - (необязательно) **Variable** `ALLOW_ORIGIN` =
     `https://noname15092025-ctrl.github.io` — чтобы воркером пользовался
     только наш сайт;
   - (необязательно) **Variable** `MODEL` = `gemini-2.5-flash`
     (можно `gemini-2.5-flash` и т. п.).
5. Скопируй адрес воркера — он вида
   `https://api-portal-agent.<твой-поддомен>.workers.dev`.

## Шаг 3. Подключить адрес к сайту

В `index.html` найди строку:

```js
var AGENT_ENDPOINT = ""; // <-- вставь сюда URL воркера
```

впиши в неё адрес воркера, закоммить и запушь. Готово — чат заработает
для всех. (То же значение можно временно задать без правки кода: открой
чат → «⚙ Настроить» → вставь URL; но это сохранится только в твоём
браузере, для всех — только через правку `index.html`.)

---

## Стоимость и лимиты

- Воркер и ключ Gemini — в рамках бесплатных тарифов денег не стоят.
- У бесплатного Gemini есть лимит запросов в минуту. Если упрётесь —
  в коде воркера можно сменить `MODEL` или подключить платный ключ
  (тот же воркер, ничего больше менять не надо).

## Безопасность

- Ключ модели виден только внутри воркера (Cloudflare Secret).
- Агент получает только **текст документации портала** (оглавление API и
  релевантные выдержки). Логины/пароли из закрытого раздела **не**
  отправляются.
- Ответ агента — предположение по документации. На сайте под каждым
  ответом стоит пометка «всегда думайте своей головой».
